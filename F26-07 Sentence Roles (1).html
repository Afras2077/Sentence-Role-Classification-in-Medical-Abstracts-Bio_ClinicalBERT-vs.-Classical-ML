Illustrative abstract, written for this page

Does knowing where a sentence sits help a biomedical model

A text-only Bio ClinicalBERT scored 0.8143 macro-F1. A logistic regression given 14 position features scored 0.8295, 1.52 points higher. We ask how far a transformer goes when it is given the same clue, on PubMed 20k RCT with 30,135 held-out test sentences.

RQ1

How accurately can classical ML (TF-IDF plus a classifier) label sentence roles?

RQ2

Do transformers significantly outperform the classical approaches?

RQ3

What does the accuracy gain cost in training time and inference speed?

    Three changes to the transformer

    PubMedBERT backbone

    Pretrained from scratch on 14M PubMed abstracts, replacing Bio ClinicalBERT, which continues from clinical notes.

    Position prefix

    Line number, abstract length and relative position are written in front of every sentence before tokenising.

    [LINE i OF N] [PCT n%]

    Class-weighted loss

    Inverse class frequency, so rare roles count for more.

    5 epochs, batch 32, max length 128, learning rate 2e-5, Colab T4, seed 42. The epoch-2 checkpoint was kept (dev macro-F1 0.8726)
